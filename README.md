# Gartengestaltung Geißler – Website

A static website in the design language of the reference site relaisrossar.it. Pages are generated with Jinja2 templates and contain no server-side logic.

## Structure

```
site/                     ← finished website (upload this folder to the hosting)
  index.html, dienstleistungen.html, dienstleistungen/*.html (11 services),
  smart-garden.html, smart-garden/*.html (3), galerie.html, kontakt.html,
  ueber-uns.html, karriere.html, impressum.html, datenschutz.html,
  sitemap.xml, robots.txt
  assets/css/main.css     ← global design system (type scale, components)
  assets/css/pages/*.css  ← page-specific styles
  assets/js/main.js       ← Lenis smooth scroll, GSAP text reveals, cursor CTA, mega menus, transitions
  assets/js/{gallery,contact,legal}.js
  assets/fonts/           ← self-hosted variable fonts (Newsreader, Hanken Grotesk)
  assets/img/r/           ← responsive WebP versions generated by the build
  assets/img/map/         ← map of the service area (OpenStreetMap data)
  assets/video/           ← hero video and Smart Garden video (Kling 3.0)
src/templates/            ← Jinja2 templates (base, partials, pages)
src/media.json            ← image assignments (generated by _tools/make_media.py)
_data/content.json        ← all texts (German)
_data/gallery.json        ← curated gallery images (categories, alt texts, focal points)
_data/einzugsgebiet.json  ← towns in the service area
_gen/                     ← AI-generated source images and videos (GPT Image 2 / Kling 3.0)
_research/                ← reference screenshots and original images from the old website
_tools/                   ← build, image and QA tools
```

## Build

```bash
_tools/.venv/bin/python _tools/make_media.py   # only after changing image assignments
_tools/.venv/bin/python _tools/build.py        # renders all pages into site/
_tools/.venv/bin/python _tools/build.py kontakt  # renders only matching pages
```

Local preview: `cd site && python3 -m http.server 8765`, then open http://localhost:8765.
Technical check (links, errors, images, overflow at 4 viewports): `python3 _tools/qa.py`

To change a text, edit `_data/content.json` and run the build again.

## Before going live – client input needed

- **Privacy policy** (`_data/content.json` → `legal.datenschutz_html`): add the hosting provider's name and address, and how many days server logs are kept.
- **Impressum:** add the VAT ID (USt-IdNr.) if the company has one.
- **Team** (`_data/content.json` → `about.team`): replace the ten placeholder names "Vorname Nachname" with the real names.
- **Team photos:** in `src/templates/pages/about.html`, each `<figure class="team-card__media" data-photo="">` contains a comment. Put an `<img>` there and the placeholder hides itself automatically.
- **Address:** the old job ad says Elsavastraße **6**; everywhere else it is **3** (3 is used throughout).
- **Contact form:** there is no backend yet. On submit the visitor's e-mail program opens with the enquiry pre-filled. To send directly instead, set a form service or your own endpoint as the form's `action` (a comment in `src/templates/pages/contact.html` explains where).
- **Fonts:** the reference uses the Adobe fonts *IvyOra Display* and *IvyStyle Sans*. If you have an Adobe Fonts licence, set up a kit, add its CSS in `base.html` and change the font variables `--ff-display` / `--ff-sans` at the top of `main.css`.
